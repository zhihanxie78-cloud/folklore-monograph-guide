# 民俗类专著阅读与写作指南（folklore-monograph-guide）

Claude Code Skill：民俗类专著（民俗志、民间信仰、庙会、传说、婚丧礼俗研究）的**四维拆解法**阅读与写作转化方法论。

> 把一本民俗类专著读成四维：**结构**（章节骨架）→ **论述逻辑**（作者怎么论证）→ **文献依据特点**（作者怎么用材料）→ **调研方面**（作者查了什么）；再把四维转化为自己的论文写作能力与田野调查清单。

## 一句话总纲

普通摘要回答"书里讲了什么"；四维拆解回答**"作者是怎么研究、怎么写出来的"**——这正是民俗学论文写作最需要从专著中偷师的部分。

## 核心流程（6 环节）

| 环节 | 内容 |
|---|---|
| 0 任务定义与 PDF 探测 | `scripts/check_pdf.py` 检测文本层；扫描版按 知识化 / 定向 OCR / 全量 OCR 三强度选路线 |
| 1 版本勘定与章节边界 | 专著 vs 论文集判定、各章原刊出处、页映射公式（印刷页 = PDF 页 − N，双锚点验证） |
| 2 四维拆解（逐单元） | 结构（逐节要点）/ 论述逻辑（核心命题 + 论证链 + 标志性论证动作）/ 文献依据特点（四分类 + 占比/用法/辨识度）/ 调研方面（13 类可勾选维度清单 + 书内证据） |
| 3 跨章整合 | 横向对比总表 + 高频文献分类清单 + 全书底层逻辑归纳 |
| 4 写作转化 | 论证手法库（先破后立/版本比较/多重叙述对照等）+ 文献使用策略 + 田野调查清单（可直接改成调研提纲）+ 论文大纲模板 |
| 5 交付与验收 | md + Word 双格式；README 诚实声明（PDF 处理方式 + 页映射验证锚点） |

## 安装（Claude Code）

将本仓库克隆/复制到 `~/.claude/skills/folklore-monograph-guide/`（Windows：`C:\Users\<你>\.claude\skills\`），即可在对话中按需触发；或直接说"用 folklore-monograph-guide 的方法拆解这本书"。

## 参考实现案例

首例：岳永逸《灵验·磕头·传说：民众信仰的阴面与阳面》（三联书店 2010，380 页纯扫描 PDF）前三章拆解——4 单元（导言 + 三章，168 页）全量 OCR 路线、页映射 −11 双锚点验证、四维拆解 + 跨章对比总表 + 文献四分类清单 + 写作转化四件套。案例输出文件保留在用户本地，不随仓库发布（详见 SKILL.md §4）。
